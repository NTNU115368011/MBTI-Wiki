# MBTI Wiki｜人格探索指南

## 專案介紹

本專案以「MBTI 人格探索指南」為主題，透過 LLM Wiki 整理人格類型、人格偏好與相關理論知識，並將 Wiki 內容自動轉換為適合初學者閱讀的 HTML 教學簡報。

本專案為一次性課程作業，主要展示 LLM Wiki 的知識整理流程，以及 Wiki 與 HTML 簡報之間的自動生成關係。

## 專案目標

- 蒐集至少 5 個 MBTI 相關資料來源。
- 利用 LLM 整理、整合及連結知識，建立 Markdown Wiki。
- 保留來源引用，讓 Wiki 內容具有可追溯性。
- 直接從 Wiki 自動規劃並生成 HTML 教學簡報。
- 透過檢查點、執行紀錄及反思，呈現 LLM Wiki 的建置流程。

## 專案架構

```text
MBTI-Wiki/
├── AGENTS.md
├── README.md
├── index.md
├── log.md
├── sources/
├── wiki/
│   ├── topics/
│   ├── concepts/
│   ├── personalities/
│   └── source_notes/
└── slides/
```

## 工作流程

1. 蒐集並匯入 MBTI 相關資料來源。
2. 逐一閱讀來源，整理摘要與引用資訊。
3. 建立及整合 Wiki 知識頁面。
4. 檢查 Wiki 的內容、連結與來源引用。
5. 直接以 Wiki 自動規劃教學章節。
6. 分批生成 HTML 投影片並進行檢查。
7. 合併 HTML 簡報，完成最終檢查。
8. 記錄執行過程、問題與改善反思。

## 專案成果

- MBTI 知識 Wiki
- 自動生成的 HTML 教學簡報
- Wiki 建置與簡報生成流程紀錄
- 執行結果及流程反思

## 使用方式

Wiki 文件以 Markdown 格式閱讀。

HTML 教學簡報完成後，可直接透過瀏覽器開啟 `slides/index.html`。
